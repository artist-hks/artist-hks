# Font licenses

The SVG artwork embeds the Latin WOFF2 subsets of these fonts as data URIs. Source font licenses are included beside the artwork.

- **Barlow Condensed** (700): SIL Open Font License 1.1. Source: https://github.com/google/fonts/tree/main/ofl/barlowcondensed
- **IBM Plex Mono** (400): SIL Open Font License 1.1. Source: https://github.com/google/fonts/tree/main/ofl/ibmplexmono

Each SVG also includes readable system-font fallbacks. No SVG requests fonts, images, or scripts from an external host.
